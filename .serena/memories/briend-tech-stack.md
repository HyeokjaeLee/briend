# Briend 기술 스택

## 모노레포 관리
- **Turbo**: 빌드 시스템 및 워크스페이스 관리
- **Bun**: 패키지 매니저 및 런타임

## 웹 애플리케이션 (apps/web)
- **Next.js v15**: React 프레임워크
- **TypeScript**: 정적 타입 검사
- **Tailwind CSS v4**: 스타일링
- **ShadcnUI**: UI 컴포넌트 라이브러리
- **tRPC**: 타입 안전 API
- **Zustand**: 상태 관리
- **PWA**: 서비스 워커 기반 오프라인 지원

## 네이티브 앱 (apps/native)
- **Expo**: React Native 개발 플랫폼
- **React Native**: 크로스 플랫폼 모바일 개발

## 소켓 서버 (apps/socket-server)
- **Socket.io**: 실시간 통신
- **TypeScript**: 타입 안전성

## 데이터베이스 & 저장소
- **Firebase Firestore**: NoSQL 문서 데이터베이스
- **Firebase Realtime Database**: 실시간 데이터 동기화
- **Firebase Storage**: 이미지 저장
- **IndexedDB**: 클라이언트 사이드 데이터 저장

## 인증
- **NextAuth.js**: 인증 라이브러리
- **Firebase Auth**: 사용자 인증 관리

## 번역 서비스
- **DeepL API**: 주 번역 엔진
- **Google Translate API**: 백업 번역 엔진

## 다국어 지원
- **i18next**: 국제화 라이브러리
- **react-i18next**: React i18n 바인딩

## 개발 도구
- **ESLint**: 코드 린팅
- **Prettier**: 코드 포맷팅
- **Husky**: Git 훅 관리
