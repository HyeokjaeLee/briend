# 환경별 개발 설정 분리 구조

## 환경 분리 전략
- **개발환경**: 로컬 Supabase Self-hosting  
- **프로덕션**: Oracle Cloud Self-hosting
- 기존 클라우드 데이터 사용하지 않고 깨끗하게 시작

## 환경설정 파일 구조
```
apps/web/
├── .env.development          # 개발환경 전용
├── .env.production.template  # 프로덕션 템플릿  
├── .env.local               # 현재 활성 설정
└── .env.local.backup        # 원본 백업
```

## 환경 전환 방법
```bash
# 개발환경 사용
cp .env.development .env.local

# 프로덕션 사용  
cp .env.production .env.local
```

## 개발환경 설정 내용
- NODE_ENV="development"
- NEXT_PUBLIC_SUPABASE_URL="http://127.0.0.1:54321"  
- DEBUG_MODE="true"
- ENABLE_LOGGING="true"
- 로컬용 소셜 로그인 키들 포함

## 프로덕션 준비
- Oracle Cloud 무료 티어 활용 예정
- ARM Ampere A1 (4 OCPU, 24GB RAM)
- 완전 Self-hosting 환경
