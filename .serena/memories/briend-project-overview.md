# Briend 프로젝트 개요

## 프로젝트 목적
여행 중 현지인과 소통할 때 언어 장벽을 해결하는 실시간 번역 채팅 애플리케이션

## 핵심 기능
- QR 코드 기반 채팅방 생성/참여 (앱 설치 불필요)
- 실시간 번역 채팅 (내 말은 상대방 언어로, 상대방 말은 한글로)
- PWA 지원으로 앱 설치 없이 사용 가능
- 게스트 모드 지원
- 개인정보 로컬 저장 (서버에 저장하지 않음)

## 지원 언어
- 현재: 한국어, 영어, 일본어
- 계획: 중국어, 베트남어, 태국어

## 번역 엔진
- 주요: DeepL API (자연스러운 번역)
- 백업: Google Translate API

## 인증 시스템
- 카카오, 구글, 네이버 소셜 로그인
- 게스트 모드 (닉네임만으로 참여 가능)

## 배포
- 웹: https://briend.vercel.app
- 네이티브 앱: 개발 중 (Expo 대기)
